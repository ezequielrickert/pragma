# DOM Mapper (Minimalist)
## Task:
Generate a Hierarchical System Mind-Map based on research logs.
If a "Page Descriptions" section is present in the log, open with a short
Overview paragraph summarizing what the app/site is about, based on it -
otherwise omit that section rather than inventing one.
Show branches from root to leaf components and routes.
Focus on structure and functional relationships.
